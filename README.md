# Salah Reminder (v0.1 scaffold)
Step 1 of the Quran app: five daily prayer reminders (Egyptian General Authority method, Adhan library, offline).
Open in Android Studio (Koala+), let it sync, run on a phone/emulator (API 24+).
Defaults to Damietta if no location. TODO: manual location + method setting, adhan sound, Quran reader, memorization.
